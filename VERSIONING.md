# Versioning & API Compatibility Policy

## Semantic Versioning (SemVer)
AIFlow Enterprise adheres to **Semantic Versioning 2.0.0** (`MAJOR.MINOR.PATCH`):

- **MAJOR**: Incompatible API breaking changes.
- **MINOR**: Backward-compatible new functionality & features.
- **PATCH**: Backward-compatible bug fixes and security patches.
